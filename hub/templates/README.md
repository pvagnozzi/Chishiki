# Hub Templates

This directory contains project scaffolding templates used by the `scaffold_project` MCP tool.

## Template structure

Each template is a directory named after the template:

```
hub/templates/
└── <template-name>/
    ├── TEMPLATE.md        ← front-matter: name, description, tags, version
    └── ...                ← source files to copy into the target directory
```
